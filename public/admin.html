Admin Login

Sign in to manage bookings, WhatsApp and settings.

Admin password is set with the ADMIN_PASSWORD environment variable. It is not stored in this repo.

Admin Dashboard

WhatsApp Auto-Send Settings

WhatsApp credentials come from environment variables: WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_ACCESS_TOKEN, WHATSAPP_TEMPLATE. Owner number: OWNER_WHATSAPP (default 917876520226).

To connect: create a WhatsApp Business app in Meta for Developers, copy the Phone Number ID and a permanent Access Token, set them in .env and restart the server. Bookings will then send automatically; until then they are marked “Not sent — API not connected”.
